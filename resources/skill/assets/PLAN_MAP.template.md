本文件只跟踪跨阶段、影响公共契约、依赖真实反馈，或会与其他计划发生关系的计划。普通一次性任务不要加入这里。

## 文档权责

- `PLAN_MAP.md` 的 `状态` 是计划级生命周期，`当前阶段` 是阶段身份指针。
- 阶段 N 完成后，阶段 N+1 默认保持 `设计中`；专项计划自己的准入复核通过后才能进入 `待实施`。
- 地图只更新当前摘要和有效证据入口；实施、部署、测试和反馈详情写入所属计划或报告，不在页首、索引或单元格内追加日志。
- 阶段准入摘要、样本矩阵和复核记录只写入专项计划，不复制到本索引。
- 专项计划记录本次行为差异和验收；现行契约优先引用已有 Schema/OpenAPI，无合适来源且需长期维护时才按需建立 `docs/specs/*.md`。同一事实不重复维护。
- 专项计划可在当前阶段声明阶段证据和追加式实施/验证记录；完成快照默认保持旧 JSON 兼容格式，发布/合规场景再显式使用 purpose 关系。
- `--drift`/`--pre-commit` 的关闭窗口只在已完成计划自身也发生变更时覆盖该计划自身和显式阶段证据，不复用已完成计划的完整影响范围。
- 计划索引固定分为 `未完成`、`已完成`、`已废弃` 三张表；`已替代`、`已合并`等不再推进的终态归入 `已废弃` 表，但保留真实状态值。

记录、归属与历史整理按所选 skill 的 planning 参考执行；表格须保持“分类标题 → 表头 → 分隔行 → 连续数据行”，不在表头前或表外追加数据行。历史页仅按需建立，不作为日常日志或第二份状态索引。
