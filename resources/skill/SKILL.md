# Plan Governance

帮助用户完成需要持续协调的工作，维护足够的计划、决策与验证证据。已有相关计划时沿用；需要持久记录阶段和依赖时才新建。任务持续多轮或涉及 API，并不自动要求治理。

## 执行原则

根据当前请求、上下文和已有授权持续推进。用户指令优先于本 skill 的流程建议；保留用户明确的实现、外部操作和验收边界。能自行查证或作可逆决定的事项自主处理；只有缺失信息会实质改变结果或超出授权时才询问，并继续不依赖该答案的工作。

首次接手读取地图、当前相关计划及必要契约；恢复只核对当前阶段、实际差异和最近证据。只实施已授权且准入的范围；实质边界变化时调整受影响计划，日常进展随工作同步。事实源与格式见 planning。

先确定当前计划的有效复核策略，再按 verification 验证；单次策略下，高风险或高影响同范围独立检查一次，修复由实施者自验。适用检查通过后完成交付；未解决问题如实保留。交付说明完成结果、必要证据和剩余事项，明确约定的用户体验验收继续有效。
